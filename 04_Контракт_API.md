## Эндпоинт

**Адрес:** /api/analyze

**Метод:** GET

## Запрос

GET /api/analyze?text=...

| Поле | Тип | Обязательно | Описание | Ограничения |
|---|---|---|---|---|
|text|string (query)|да|Текст для анализа на английском языке|minLength=1, maxLength=2500; только латиница|

## Ответ при успехе

```json
{
  "suspected_author": "rowling",
  "score": 0.87,
  "style_features": "стилистические характеристики автора",
  "top_scores": [
    { "author": "tolkien", "score": 0.62 },
    { "author": "lewis",   "score": 0.55 },
    { "author": "martin",  "score": 0.31 }
  ]
}
```

| Поле | Тип | Описание |
|---|---|---|
| `suspected_author` | string | Наиболее вероятный автор |
| `score` | float (0…1) | Уверенность модели |
| `style_features` | string *(заглушка)* | Стилистические характеристики автора. `TODO`: заменить на реальный тип |
| `top_scores` | array[Score] | Остальные кандидаты по убыванию |
| `top_scores[].author` | string | Имя автора |
| `top_scores[].score` | float (0…1) | Вероятность принадлежности текста автору |

## Ответ при ошибке

```json
{ "detail": { "error": "empty_text", "message": "Текст не должен быть пустым" } }
```

| Ситуация | Код | HTTP | Наличие |
|---|---|---|---|
| Пустой текст | `empty_text` | 400 | есть |
| Текст длиннее допустимого | `text_too_long` | 400 | есть (+`limit: 2500`) |
| Не латиница / другой язык | `unsupported_language` | 400 | есть |
| Модель не загружена | `model_unavailable` | 503 | есть |

## Ограничения

**Максимальная длина текста:** 2500 символов 

**Ожидаемое время ответа:** не задано — заглушка отвечает практически мгновенно (работает `random`); для реальной модели требует уточнения  

**Нужен ли индикатор загрузки в интерфейсе:** не нужен
