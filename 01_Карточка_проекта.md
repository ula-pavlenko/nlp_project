## Задача

**Вход:** {text}

**Выход:** {author, score, all_scores, style_features}

**Кому и зачем это нужно:** Работа адресована филологам-текстологам, атрибуционным комиссиям, издательствам, архивам и исследователям массовой литературы. Цель исследования - автоматическое разрешение проблемы установления авторства. Работа включает определение стилистических особенностей и концептов конкретных авторов единого жанра, проведение комплексного стилометрического анализа и автоматизацию задачи установления авторства на фрагментированных текстах. При дальнейшей настройке и обучении может использоваться для определения предполагаемых авторов анонимных произведений либо произведений с неопределенным авторством.

## Проверка выбора темы

**Готовая модель, на которой проверяли:**

TF-IDF (1–2-граммы, до 20 000 признаков) + Logistic Regression с class_weight='balanced';

CountVectorizer + Multinomial Naive Bayes;

тот же TF-IDF + LogReg, но обученный только на служебных словах (артикли, предлоги, союзы, местоимения) — классический стилометрический приём;

тот же TF-IDF + LogReg, но на коротких фрагментах (~250 слов).

Объём проверки: 20 примеров.
20 фрагментов по ~1000–1200 слов из открытых текстов Project Gutenberg, по ~3 фрагмента на каждого из 7 авторов. Train и test не пересекаются по произведениям. Разметка — автор из метаданных издания.

**Результат готовой модели:**

TF-IDF + LogReg (полный словарь): Accuracy = 0.85, Macro-F1 = 0.848, Top-3 = 1.00.

Naive Bayes: Accuracy = 0.65, Macro-F1 = 0.562.

TF-IDF + LogReg только на служебных словах: Accuracy = 0.70, Macro-F1 = 0.677.

TF-IDF + LogReg на коротких фрагментах (~250 слов): Accuracy = 0.80, Macro-F1 = 0.810.
Случайное угадывание (1/7) = 0.143.

Матрица ошибок (полный словарь): 4 из 7 авторов распознаны без ошибок; все 3 ошибки — смешение Dunsany / Verne / Wells с Burroughs (авторы со схожей приключенческой лексикой).

**Почему этого недостаточно:**
Готовая модель справляется хорошо на полном словаре (Macro-F1 = 0.848), потому узнавание идёт по лексике (имена, топонимы, характерные слова), а не по стилю. Как только мы убираем лексику и оставляем только служебные слова (чистый стилометрический сигнал), Macro-F1 падает до 0.677 — то есть около 20% качества держалось именно на лексике. Дополнительно, на коротких фрагментах (~250 слов) качество тоже снижается (Macro-F1 = 0.810 против 0.848), что критично для нашей задачи: мы работаем с фрагментированными текстами и стилизациями. Наконец, готовая модель не выдаёт интерпретируемых style_features, которые нужны филологам-текстологам.
Отдельно стоит отметить, что среди открытых решений на Hugging Face нет ни одного, которое сочеталось бы сразу с тремя нашими требованиями: работа с художественным текстом жанра фэнтези, устойчивость к фрагментированным текстам и выдача интерпретируемых стилометрических признаков. Даже те модели, которые запускаются, не дают style_features и обучены на других доменах. Кроме того, удобных и доступных сайтов и приложений также практически нет в открытом доступе.

## Данные

**Материал:** иностранные литературные произведения жанра фэнтези (Дж. Р. Р. Толкин, К. С. Льюис, Урсула Ле Гуин, Роберт Джордан, Брэндон Сандерсон, Джордж Р. Р. Мартин, Терри Пратчетт)

**Источник:**  оригинальные англоязычные издания произведений; тексты оцифрованы и приведены к единому формату. Дополнительные корпуса — открытые репозитории GitHub.

**Откуда берётся разметка:**  автоматически наследуется из метаданных источников (выходные данные изданий, библиографические записи). Каждому фрагменту присваивается метка автора-эталона, название произведения, год, язык и т. д. 

**Предполагаемый объём:**  не менее 500 слов на фрагмент; целевой размер фрагмента — 1000–2000 слов. Общий объем корпуса — не менее 5–10 млн слов, по 500–1000 фрагментов на каждого автора.

**Что есть на руках прямо сейчас:**  корпус текстов, список авторов и произведений, общее понимание стилистических особенностей авторов.

## Метрика

**Основная:** Macro-F1 (устойчива к дисбалансу классов и является стандартом в задачах атрибуции авторов).
*Дополнительные метрики*: Accuracy, Top-3 Accuracy, матрица ошибок для анализа смешения стилей. 

**Обоснование:**  `Macro-F1`: она усредняет качество по каждому автору отдельно, поэтому каждый класс получает равный вес независимо от объема текстов в корпусе, что критично при различающихся объемах произведений. `Accuracy` приводится как базовый показатель для сопоставимости с другими работами, `Top-3 Accuracy` — как индикатор стилистической близости авторов. `Confusion matrix`(матрица ошибок) используется для интерпретации смешения между авторами. Accuracy в одиночку недостаточно, так как она может быть завышена за счет доминирующего класса и не отражает качество различения остальных.

**Целевое значение:** метка автора `author` из разметки

**Пороговое значение неработоспособности:** модель считается неработоспособной, если ее `Macro-F1` на тестовой выборке статистически не отличается от уровня случайного угадывания (1/N), т. е. ~ 14.3%, с учетом доверительного интервала.

## Минимальная версия

Одностраничное приложение с полем ввода текста и тремя блоками результата — вердикт (автор + уверенность), распределение вероятностей по авторам (bar chart) и стилевой профиль текста (набор выявленных стилометрических признаков в сравнении с эталонным профилем предсказанного автора). Реализуется через один запрос к API, без истории и авторизации.
