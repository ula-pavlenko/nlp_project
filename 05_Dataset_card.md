# Dataset card

**Срок:** веха 1

## Краткое описание

Корпус англоязычных художественных текстов пяти писателей-фантастов (фэнтези) — Льюиса, Мартина, Пратчетта, Роулинг и Толкина. 
Предназначен для задачи стилометрического анализа — определения авторства передаваемого фрагмента текста. 
Объем обучающего корпуса — 6862 фрагмента (~3,5 млн слов) из 26 произведений.

> Два-три предложения: что за набор, для какой задачи, какого объёма.

## Происхождение

**Источник:** электронные версии книг 

**Способ получения:** скачивание .txt-файлов и нарезка на фрагменты ≈500 слов (по границам слов)

**Дата сбора:** 20.09.2026

**Критерии отбора:** один писатель — одна коллекция; жанр фэнтези; тексты преимущественно на английском

**Скрипт сбора:** dataset/seed.py выполняет загрузку в MongoDB. Расчёт стилевых признаков — dataset/styles.json

## Подготовка

**Нормализация:** исходный текст разбит на фрагменты ~500 слов по границам слов; регистр, пунктуация сохранены. Установлен фильтр на язык (функция `is_russian()` в dataset/seed.py): удалены тексты на русском языке

**Дедупликация:** метод — проверка точных совпадений по MD5 text; удалено 0 записей (дубликатов не найдено)

**Объём до и после:**  7222 ->  6862 фрагмента (полностью удалена русскоязычная версия книги Роулинг "Дары смерти")

**Три найденных дефекта данных:**

1. **Что**: 333 фрагмента на русском языке в rowling.jsonl (книга «Дары Смерти» — 100% русский перевод; остальные книги автора на английском).  
**Что сделали**: в seed.py добавлен фильтр is_russian() — русские чанки не попадают в MongoDB; в исходных .jsonl они пока остаются.

2. **Что**: внутри авторских коллекций смешаны разнородные произведения — нарушена чистота стилометрического профиля: у Мартина присутствуют не-фэнтези тексты (Dealers Choice, Double Solitaire), 
у Пратчетта — соавторские The Science of Discworld (со Стьюартом) и The Long Earth (с Бакстером).  
**Что сделали**: не устранено; требует решения — исключать эти произведения или помечать их отдельным признаком/полем.

3. **Что**: несогласованный формат поля source: разные домены (.ru, .com, RuLit_Net, RuLit_Me), транслитерация имен (Rouling вместо rowling). 
**Что сделали**: не устранено; при построении вложенного документа source используется как ключ без нормализации.

## Ограничения

> Обязательный раздел.

**Систематические перекосы:**  
- источник: только теневые библиотеки, оцифрованные .txt, возможны артефакты парсинга или OCR;
- период: произведения XX–XXI вв., разные десятилетия у разных авторов — сдвиг языковой нормы;  
- категория (автор): дисбаланс по числу фрагментов (Роулинг 26% против Льюиса 14.9%); внутри авторов доминирует одно произведение (у Толкина омнибус 'The Lord of the Rings' — 1068 из 1568 ед., ~68%; у Льюиса «Нарния» — 646 из 1023);  
- язык: 4,6 % русских фрагментов при английском как целевом языке (удалены из корпуса)

**Для чего набор непригоден:**
- обучение многоязычных моделей (корпус содержит англоязычные тексты);  
- задачи, где важна чистая жанровая принадлежность (присутствуют не-фэнтези и соавторские тексты);  
- оценка без учета дисбаланса классов — метрики будут смещены к Роулинг/Толкину.

**Что осталось спорным:** статус соавторских произведений (Пратчетт+Стюарт/Бакстер, возможно Мартин); нужна ли нормализация source

## Лицензия и авторы 
Лицензия: не определена; исходные тексты — объекты авторского права, скачаны с теневых библиотек. 
Датасет пригоден только для внутренних учебных/исследовательских целей, не для распространения. Требует юридической проверки.
