## Отправная точка

**Подход, с которым сравниваем результат:** TF-IDF + Logistic Regression (полный словарь) — Accuracy = 0.85, Macro-F1 = 0.848.  
**Значение, которое считаем известным уровнем:** Macro-F1 = 0.848 (на полном словаре) и Macro-F1 = 0.677 (на служебных словах — чистый стилометрический сигнал).  

### Изменение фокуса исследования

В ходе проверки замысла было принято решение **сместить фокус с классиков жанра (Толкин, Льюис, Ле Гуин) на более современных авторов фэнтези**. Причины:

1. **Современные авторы пишут в более сопоставимых условиях** — единый временной период, схожие издательские требования, близкий объём произведений. Это снижает риск, что модель будет различать авторов по эпохе, а не по стилю.
2. **Больше данных для обучения** — современные авторы активно издаются, тексты доступны в цифровом виде, что позволяет набрать целевые 5–10 млн слов.
3. **Фанфики как тестовая выборка** — по произведениям современных авторов существует большое количество фанфиков (на платформах Archive of Our Own, FanFiction.net и др.). Фанфик — это текст, написанный **другим автором** в мире и стиле оригинала. Это идеальный материал для проверки гипотезы: если модель обучена на оригиналах, сможет ли она «узнать» стиль целевого автора в тексте, написанном его фанатом? Если да — модель улавливает именно стилометрические признаки, а не лексические маркеры (имена героев, топонимы), которые в фанфиках тоже присутствуют.

Таким образом, тестовая выборка из фанфиков позволяет проверить **устойчивость модели к стилизациям** — ключевое требование нашего проекта.

## Проверка замысла

**Что проверяли:** способность готовых моделей решать задачу атрибуции авторов на материале стилизованных произведений жанра фэнтези, включая работу с фрагментированными текстами и выдачу интерпретируемых стилометрических признаков.  
**Объём:** 20 примеров (20 фрагментов по ~1000–1200 слов из открытых текстов Project Gutenberg, по ~3 фрагмента на каждого из 7 авторов; train и test не пересекаются по произведениям).  
**Что получили:** TF-IDF + LogReg (полный словарь) — Accuracy = 0.85, Macro-F1 = 0.848, Top-3 = 1.00; Naive Bayes — Accuracy = 0.65, Macro-F1 = 0.562; TF-IDF + LogReg только на служебных словах — Accuracy = 0.70, Macro-F1 = 0.677; TF-IDF + LogReg на коротких фрагментах (~250 слов) — Accuracy = 0.80, Macro-F1 = 0.810. Случайное угадывание (1/7) = 0.143.  
**Ссылка на код:** [nlp_project](https://github.com/ula-pavlenko/nlp_project)  

**Вывод:** замысел работоспособен частично. Готовые модели показывают высокое качество на полном словаре, но оно держится на лексике, а не на стиле. При переходе к чистому стилометрическому сигналу (служебные слова) Macro-F1 падает до 0.677. На коротких фрагментах качество также снижается. Открытые решения на Hugging Face не сочетают все три наших требования (фэнтези, фрагментированные тексты, интерпретируемые `style_features`). Требуется собственная модель, ориентированная именно на стилометрические признаки. Дополнительно принято решение перейти на современных авторов и использовать фанфики как тестовую выборку для проверки устойчивости к стилизациям.
